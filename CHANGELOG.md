# Changelog

## 0.1.0 — 2026-08-16

- Added a nonmodal state-synchronized RDKit depiction panel for PyMOL 2.5 and
  3.1.
- Added external-process precomputation, persistent PNG caching, health checks,
  cancellation, and per-state failure handling.
- Added editable compound metadata, compound-level marking, selected-compound
  review, jump-to-pose, and atomic CSV export.
- Added a standalone Plugin Manager ZIP and an optional PLIP Pose Inspector
  0.4 launcher.
